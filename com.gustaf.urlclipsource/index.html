How this works

The host editor has no API for loading a URL into its Source Viewer, so this panel is the source viewer. The prepared MP4 is a real, edit-ready file you can drag onto the timeline. The host will place it at the drop point.

About the Source Viewer

The official host scripting API does not expose a way to open a URL in the Source Viewer or to drag items from a third-party window into the timeline. This plugin gives you the same workflow in a dedicated source panel, then hands the host a normal media file that supports native drag-and-drop.
